Existing `skill.md-main` provenance identifies Addy Osmani, while the separate source key `agent-skills` identifies Bhushan Modi; neither key is silently reassigned. This expansion enhances `writing-plans`, `executing-plans`, `code-simplification`, `feature-spec`, `code-review`, `frontend-ui-engineering`, and `release-check` in place. IDs, paths and composition are retained. Persistent planning is merged into existing workflows, so no competing planner or forced global router dependency is added.

This bounded source review did not locate an earlier Master Expansion Plan in the repository paths searched; the attached full expansion request defines the current scope. See [EXPANSION-PROGRESS.md](EXPANSION-PROGRESS.md) for the project discovery/checkpoint result. Do not interpret this source matrix as proof that deferred upstream frameworks were integrated.

## Optional adapters and acceptance limits

See [OPTIONAL-INTEGRATIONS.md](OPTIONAL-INTEGRATIONS.md). Graphify code-only extraction is local according to its reviewed README, but semantic document/media processing can call configured model backends. Nyx never invokes either. OmniRoute liveness confirms one local public health endpoint only, not identity, database readiness, model routing, provider access, quota or credential validity. Both adapters remain optional and default disabled.

Tests use local fixtures and a synthetic loopback HTTP server. No live Graphify installation, OmniRoute instance, Figma account, Supabase database, Stripe account, or third-party dynamic reverse environment was exercised. No WSL/Linux/native platform acceptance is inferred from these Windows Node tests.

## Future import gate

Before a specific upstream file is imported: pin its revision; review its exact license, NOTICE and transitive resources; inspect scripts and lifecycle/network/credential behavior; preserve required attribution; map capabilities and risk; remove host-policy overrides; verify offline/absent-tool behavior; and test that exact platform artifact. Copyleft or proprietary/terms-governed material must not be relabeled as MIT. Missing evidence is a documented deferral, not an authorization to install or execute upstream content.
