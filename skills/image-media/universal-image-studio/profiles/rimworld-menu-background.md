# RimWorld Menu Background Image Studio

Opt-in for RimWorld menu-background work. Default to strict style matching within this profile. Use approved project references for style and the actual source for identity. Inventory all accessible images, including new candidates. Filenames such as MenuBG_Amiya.png or MenuBG_Odyssey.png are examples, not evidence of access or approval.

Preserve observed face, eyes, hair, species traits, silhouette, outfit, props and pose. Keep 2D anime characters with varied line weight and cel shading over cinematic semi-realistic space environments when consistent with the approved references. Use cyan/teal rim light where motivated by the scene. Check hands, hair, ears, horns, tails and multi-character separation.

Default target: 2048 × 1152 PNG, subject left or center-left, roughly 35% on the right for menu readability. Follow actual UI screenshots and user settings when supplied. Avoid unintended text and logos. Review with a UI overlay if possible and record in-game QA separately. Keep source resolution for the pixel-preserved master before making any resized derivative.
