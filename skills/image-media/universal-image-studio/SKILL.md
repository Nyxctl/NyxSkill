# Universal Image Studio

Use for reference-driven image generation, visual analysis, targeted edits, and image QA. For UI integration and accessibility use the UI Illustrations workflow.

Read [Shared Core](references/core.md). Use [local commands](README.md) for inventory, inspection, compositing and pixel verification. Load the [RimWorld profile](profiles/rimworld-menu-background.md) only for an explicitly selected profile or confirmed RimWorld menu-background project. Otherwise use general.

Use only available built-in image tools included in existing access, or offline local operations. If native image tools are absent or exhausted, report the unavailable step and continue with feasible analysis, local work, or a prompt. Never fall back to a metered API, API key, paid CLI or automatic purchase. Use one output by default.

For strict edits, obtain a source-aligned patch and approved mask, composite locally, then verify the exported PNG. Report semantic and pixel QA separately. A native edit without verification is a soft lock.
