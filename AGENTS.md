# NyxSkill project instructions

Before finishing a task that included implementation, debugging, or operational work in this repository, check for one reusable workflow that the task verified. Apply this check even when the user did not mention NyxSkill or ask for a skill. If the workflow has a clear trigger, repeatable steps, and evidence of its outcome, load `skills/core/writing-skills/SKILL.md` and write a staged draft or a revision draft. Follow project and host write permissions and any explicit user opt-out. Report the draft path in the handoff. Skip routine work, unresolved attempts, and ideas already covered by an existing skill or draft.

For Learning Loop commands in this checkout, use the repository build via `node dist/src/cli.js`. The CLI on PATH can be a different installation. See `docs/LEARNING-LOOP.md` for input formats and evidence requirements.
